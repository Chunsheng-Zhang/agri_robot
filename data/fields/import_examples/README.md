# 地块边界导入示例

这两个文件是随机生成的合成地块，供网页导入、地图显示和规划测试使用，不是实际测量的土地边界。未进行实车验证，也未启动导航。

| 文件 | 形状 | 顶点数（不含闭合重复点） | 面积 |
| --- | --- | --- | --- |
| `concave_field_a.geojson` | L 形凹多边形 | 6 | 1739.238 m² |
| `concave_field_b.geojson` | 边缘带凹口的多边形 | 8 | 1624.512 m² |

生成随机种子为 `20261113`。经纬度采用 WGS84，统一使用项目固定原点：纬度 `36.6468527633281`、经度 `117.021433066391`，投影 EPSG:32650；地块位于该原点附近。已经通过项目 `agri_path_planning.field.load_field` 的读取及几何有效性检查，确认边界闭合、无自交、确实为凹多边形。几何检查不代表所有作业幅宽、地头或转弯参数都能规划成功。

## 使用方法

1. 打开 Web“全覆盖规划与跟踪”栏目，点击“导入文件”。
2. 选择其中一个 `.geojson` 文件，核对地图轮廓并填写任务名称。
3. 核对作业幅宽、车辆尺寸等参数，然后点击“保存任务”。导入纯边界不会导入速度或控制参数。
4. 点击“生成覆盖路径”或“一键优化规划”；需要持久保存预览路径时，另点“保存规划路径”。导入、保存和规划均不会自动行驶。

## 两个栏目的文件格式

当前实现见 `agri_web/src/components/tasks/TaskEditor.vue`，文件不超过 2 MiB。

**多点导航：**支持 `.csv` 和 `.json`。CSV 第一行必须包含 `longitude`、`latitude`，可选 `dwell_time`（秒，缺省 2）。各数据行按顺序作为导航目标，不是地块边界。

```csv
longitude,latitude,dwell_time
117.021433066391,36.6468527633281,2
117.021545000000,36.6469430000000,2
```

简单航点 JSON：

```json
{"waypoints":[{"longitude":117.021433066391,"latitude":36.6468527633281,"dwell_time":2}]}
```

**全覆盖：**支持 `.geojson` 和 `.json`。本目录示例采用 GeoJSON `Feature` 包装单个 `Polygon`，每个坐标为 `[经度, 纬度]`，外环首尾坐标相同。也可直接使用 `Polygon` 对象；后续坐标环表示孔洞/禁入区。当前导入器不支持 `FeatureCollection` 或 `MultiPolygon`。

```json
{
  "type": "Feature",
  "properties": {"name": "示例地块"},
  "geometry": {
    "type": "Polygon",
    "coordinates": [[
      [117.0214,36.6468],
      [117.0218,36.6468],
      [117.0216,36.6470],
      [117.0218,36.6472],
      [117.0214,36.6472],
      [117.0214,36.6468]
    ]]
  }
}
```

全覆盖还支持项目边界 JSON：`{"points":[{"longitude":...,"latitude":...},...]}`，或 `{"rings":[[外环点对象...],[孔洞点对象...]]}`。这里的省略号是结构说明，不是可以直接导入的 JSON 内容。

两个栏目均可导入各自页面“导出任务”生成的完整任务 JSON，其中包含任务类型、参数和坐标原点；任务类型必须与当前栏目一致。地块示例的 `properties.name` 仅为说明，纯 GeoJSON 导入后任务名称需在页面中填写。
