# PP速度与参考曲率自适应前视接入

2026-11-27，用户在确认实车PP此前仅随速度调整前视后，明确要求“修改成用新的PP”。本次接入此前独立离线验证的速度/参考曲率公式，同时同步默认仿真PP。没有增加双前视、论文中的模糊控制、Stanley补偿或转角PID。

## 当前公式与参数

```text
Ld = clip((L0 + Tv × |v|) / (1 + K × |kappa_preview|), Lmin, Lmax)
```

| 参数 | 当前值/来源 | 含义 |
| --- | --- | --- |
| L0 | 当前任务的lookahead | 基础前视，旧任务数值保留 |
| v | 跟踪器收到的速度反馈 | 实车继续使用MGX定位转换的里程计速度 |
| Tv / lookahead_gain | 0.35 s | 速度增益 |
| K / curvature_gain | 0.25 m | 参考曲率增益 |
| Lmin / lookahead_min | 0.65 m | 前视下限 |
| Lmax / lookahead_max | 1.05 m | 前视上限 |
| curvature_window | 1.0 m | 向前参考弧长窗口 |

曲率为窗口首末参考切向的最短角差除以窗口弧长，不使用当前指令角速度推算。窗口和目标点均限定在当前分段；到停车转向或换向点前，切向取当前段内侧，不读取下一段切向。参考曲率左右转取绝对值参与前视。端点不足窗口长度时使用剩余窗口；窗口小于等于1微米时曲率记0。保留原目标离散顶点选择和实际目标弦长控制公式。

例如L0=0.8m、速度反馈0.46m/s：直线前视约0.961m，曲率1/m时约0.7688m。旧任务中设定小于0.65m或较大lookahead时，也受新前视限幅约束。任务速度、角速度上限、到点判定、接近起点、航向对齐、暂停恢复和停车换向的原策略没有调参。

生产默认参数位于`agri_robot_ws/src/agri_path_tracking/agri_path_tracking/algorithms.py`的`PP_DEFAULTS`；本地仿真对应`tracking_simulation/four_controler/four_controler.py`及YAML的`tuning.pp`。仿真不调用实车command，二者通过输出一致性验证。旧仿真YAML缺失新字段时自动补齐默认值。

## 调参与实时计算

前视部分共6个设定量：L0、速度增益、曲率增益、前视上下限、曲率窗口；速度和曲率是运行输入，不需要人工逐帧填写。另有虚拟轴距0.16m、后轴偏移0m和虚拟转角上限35°这3个几何适配参数。常规调优应先固定几何参数及前视边界/窗口，通过离线对照研究L0和曲率增益的影响，而非同时调整全部参数。

当前是“固定系数＋运行中自动计算前视”，不是在线学习或人工热调参。Web只暴露L0（PP基础前视距离）；覆盖页需空闲时修改、保存并规划/加载匹配路径，再明确开始；独立路径跟随页在空闲时修改、明确开始后生效。修改L0不需要重启整个项目。RUNNING、PAUSED、ACQUIRING状态拒绝更新任务参数，所以只点击暂停不能更改参数，需结束或取消本轮任务。

其他PP系数目前是生产代码默认值，不是已声明的ROS运行参数，也没有Web输入框。修改仿真`tuning.pp`后下一次离线运行读取；实车修改生产默认值需要重新加载相关进程。只修改`config/jetson_system.yaml`、仿真YAML或猜测`ros2 param set pp.curvature_gain`不会让这些系数在实车上生效。若后续需要网页调优，应明确新增参数校验、实车节点配置入口和实验快照；行驶中热更新尚未实现。
