# 覆盖路径保存与复用

2026-11-09。仅完善今后生成的路径，不恢复或回填此前历史任务。

1. 保存覆盖任务，点击“生成覆盖路径”或“一键优化规划”。
2. 成功后先在地图预览，点击“生成覆盖路径”右侧的“保存规划路径”。按钮变为“规划路径已保存”，左侧当前任务下面立即列出本版本最近10条已保存路径；一键优化结果使用同一保存按钮。
3. 以后点击任务默认预览最新已保存路径，也可点击指定路径。选择不会切换车辆模式、加载控制器或运动；在“已保存覆盖路径”中点击“加载此路径”，要求覆盖模式、控制/规划空闲，任务版本、配置、固定原点、路径指纹和净空一致，倒车按任务明确选项验证。
4. 加载成功为就绪状态，再单独点击“前往起点并开始覆盖”。仍需定位与安全检查，不自动解除急停或取得运动控制权。刚生成的当前就绪路径也可以直接开始；要留作以后复用，应先点击保存规划路径。

“保存任务”只保存边界和参数，不等于保存某条规划结果。生成时路径文件已自动落盘供本轮实验留档，新增“保存规划路径”会校验完整几何、版本、原点和指纹，并持久标记为可从左侧复用；不额外复制一份相同路径。保存无需ROS控制权，不能触发加载、模式切换、解除急停或开始。重复保存同一条为幂等操作，不重复生成列表项。

每次加载新建`data/experiments/<新记录>/`，复制参考路径及配置来源，写`source_plan_id`关联原路径；本轮原始定位、速度、轨迹及报告都保存在新目录。原路径目录、实验采集和历史结果不被覆盖。重新执行从路径开头开始，不是从之前的中断进度继续。

新生成记录先标记`plan_save_required=true`，明确保存后写入`saved_plan_version=1`、`plan_saved_at`并将待保存标记置false，才进入复用列表；之前版本已经标记保存的记录继续可用，未标记的历史不补录。编辑任务后需保存并重新规划，新版本不复用旧配置。左侧路径列表独立于运行记录表50条限制，每个当前任务版本最多显示10条；列表摘要不带全量路径数组，点击时再加载几何。

接口：`POST /api/missions/{identity}/plans/{plan_id}/save`明确保存当前就绪规划；`GET .../path`只读预览已保存路径；`POST .../load`明确加载，经唯一覆盖适配器`/planning/load`发布`/reference_path`。保存只写本轮记录元数据并刷新列表，不调用ROS。开始仍是原任务开始接口，网页不能绕过安全控制。
