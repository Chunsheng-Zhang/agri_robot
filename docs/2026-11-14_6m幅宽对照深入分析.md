# 6m幅宽对照深入分析

基于2026-11-14已冻结的50地块实验结果，只重新统计已有路径和候选，没有重新规划、修改算法、改变权重或操作车辆。原始实验与方法见[50地块对比结果](2026-11-14_50地块对比实验结果.md)及[实验方案](2026-11-14_50地块对比实验方案.md)。

结论：当前一键优化有覆盖收益，但额外转弯是平均综合代价落后的最大贡献项；分区和窄区补行值得优先做消融。不能据此直接宣称所有地块应取消分解，或把差异归结为原生TSP优于自定义TSP，因为两者都使用原生TSP。

## 可比范围与总体结果

双方均47/50成功。`nl_field_22`原始无效，`ee_field_9`、`ee_field_92`均因现有采样点容量等原因没有完整可行解；6m组没有外部实验超时。以下质量比较只取同一47块成功地块，未把失败填零。

| 指标 | 当前一键均值 | 原生组合均值 | 当前减原生 |
| --- | ---: | ---: | ---: |
| 覆盖率 | 99.3302% | 98.8897% | +0.4406个百分点 |
| 重复覆盖率 | 2.0191% | 1.5568% | +0.4623个百分点 |
| 路径长度 | 4903.65m | 4827.13m | +76.52m，均值比+1.59% |
| 停车转向数 | 72.02 | 61.68 | +10.34，均值比+16.76% |
| 综合代价J | 0.193891 | 0.188634 | +0.005257，均值比+2.79% |
| 规划及归档耗时 | 66.01s | 22.53s | 均值约2.93倍 |

“均值比”是两列均值之比，不是逐地块百分比变化的平均，不能混用。耗时为四进程并发主机单次运行，包含归档、不含独立矢量复核，不是严格串行或Jetson实时性能测量。

覆盖在35/47块更高，重复在30/47块更多，路径在35/47块更长，转向在32/47块更多、8块相同。综合J当前胜19块、原生胜28块；差值中位数+0.001397，均值95%探索性bootstrap区间[0.002466,0.008339]。去掉差距最差3块后，余下44块平均差仍+0.003165，故不能只归因于一个极端反例；此为事后敏感性分析。

两输出近似Pareto比较：当前四目标占优4块、原生占优7块、各有取舍36块。覆盖/重复容差0.01个百分点、长度0.1m、转向0次，仅比较两个选定输出。

## 覆盖收益的实际量级

47块合计129.7148ha。按面积加权，覆盖99.4114%/99.0560%，重复1.7752%/1.2407%；当前多覆盖约4610.22㎡，同时多出约6932.96㎡至少两次经过区域。该重复区域不是累计多次作业面积，不能把两者直接相减当收益，也不能等同能耗或压实实测。

逐地块平均漏覆盖率从原生1.1103%下降至当前0.6698%，约减少39.7%。所以0.44个百分点的覆盖提升不能简单说没有意义，但要检查换来的转弯和重复是否符合任务偏好。

## 综合代价差来自哪里

逐地块按生产公式重新计算四项贡献再取平均，不能先把平均长度/平均面积代入非线性公式：

`J=0.40(1-C/100)+0.25 O/100+0.20 L/(L+A/W)+0.15 N/(N+max(1,2√A/W))`

其中C、O单位为百分数，A为扣孔洞地块面积，W=6m。平均差值精确分解：

| 贡献项 | 当前减原生，对J的贡献 |
| --- | ---: |
| 漏覆盖减少 | −0.001762290，改善 |
| 重复增加 | +0.001155743，变差 |
| 路径变长 | +0.000725848，变差 |
| 转弯增加 | +0.005137464，变差 |
| 合计 | +0.005256765 |

覆盖收益本身成立，但被其余代价抵消，转向项是最大的正贡献。这是评分分解，不是因果消融；不能以此直接改权重让当前结果胜出。

## 候选与分区证据

原生47个最终选定方案全部为NONE，即不做几何分解、仍裁剪保留孔洞并使用完整Route。它们不是直线穿越障碍物，最终均通过共同净空检查。在47块中，BCD至少产生一个可评价完整方案的有33块、梯形有3块；其余部分分解候选被空条带/连接检查等拒绝。因此“不分解全部胜出”只针对本轮候选集合，不能推广为分区无用。

原生选定条带目标：NSwath 28块、NSwathModified 18块、SwathLength 1块。TSP设置自动35块、guided 12块。名称表示原生角度搜索目标，不是最终四目标函数；所有最终候选都以同一J比较。

当前选定方案平均4.94个分区、28.04行；原生1个分区、24.45行。当前有30/47块选多分区、19/47块含窄区中线保留行。多分区30块中当前J胜8块、平均差+0.007169；单分区17块中当前胜11块、平均差+0.001881。这是形状不同的观察分组，不能据此证明分解造成全部差距。

当前最终方案46/47没有选择额外边界补行集合，仅1块选择。因此不能把本组整体落后简单归因于“补边功能加了太多行”；窄区保留行、沿边起排相位、方向及分区连接需分别验证。

当前平均原生路由调用125.77次，对照12.77次。它解释了部分计算负担，但不能把调用次数比直接等同耗时比，原生内部角度搜索本身也有成本。

## 带孔地块与典型实例

成功的6个含孔地块，当前综合J全部更差；平均覆盖仅+0.0975个百分点，却多19.67次转向、J多0.011295。无孔41块当前胜19块，平均覆盖+0.4908个百分点、转向+8.98、J多0.004373。含孔样本少，且面积/形状混杂，当前证据足以优先排查障碍连接，不能作为普遍定论。

`nl_field_729253`有1孔、4.334ha，是直接的带孔反例：

| --- | ---: | ---: |
| 覆盖率 | 99.3831% | 99.1173% |
| 重复率 | 3.3634% | 1.0314% |
| 长度 | 7895.48m | 7429.87m |
| 转向 | 104 | 52 |
| 分区/行数 | 12/35 | 1/23 |

多0.2658个百分点覆盖，换来465.61m路径、52次转向和2.3320个百分点重复，当前J0.205290、原生0.171772。[图册第42页图像](../.diagnostics/fields50_20261114/figures/42_nl_field_729253.png)。

当前也有同时改善四项的实例：无孔凹地`nl_field_105`当前覆盖+1.0634个百分点、重复−0.5976个百分点、长度−13.02m、转向−6，J0.202399/0.212073；当前为3个分区，原生不分解。它说明保留分区候选有价值，不能一刀切。[第15页图像](../.diagnostics/fields50_20261114/figures/15_nl_field_105.png)。

`ee_field_136`的当前最终方案本身只有1分区，仍有83次转向、原生21次；原生方向邻域在当前搜索中被细碎分区和窄区保留行抬高代价，最后选了另一个方向。这个反例说明应检查整条候选生成链，不能仅凭最终分区数量解释。

## 下一步应验证什么

1. 同一评分下先纳入原生不分解最佳布局作为候选底座，再比较现有沿边/分区布局；若底座可行，应避免候选生成阶段排除它。
2. 保留分区能力，对窄区保留行做覆盖增益消融，不因有分区就机械补一行；连接仍使用完整原生Route并校验净空。
3. 对含孔地块单独分析作业行与过渡连接，分别统计长度、转向和重复来源，不通过删安全检查改善数字。
4. 固定权重和50块样本，加入未参与调参的留出地块；控制并发/种子重复计时，再判断效果和稳定性。

以上均为建议，未在本轮修改生产代码。当前证据不支持先换PSO、NSGA-II或重新调整权重；现有候选表示和布局差异应优先核查。

所有指标为规划几何预测，机具沿连接段也按开启计算。6m组只改圆盘等效作业幅宽，车体仍0.45×0.2m，不能证明真实6m刚性机具地头旋转安全，也不是实车作业精度、能耗或工时。
