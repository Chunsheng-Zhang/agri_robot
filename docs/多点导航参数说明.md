# 多点导航参数说明

2026-11-04。对应 `agri_waypoint/controller.py` 的独立目标点几何控制器。

## 到点距离

默认 `arrival_tolerance=0.1` m。控制器用同一固定 map 基准下的车辆 base_link 位置与目标点计算距离 d；当 d≤0.1 m 时输出零速度，进入该点停留阶段，然后切换下一点。此时不要求车辆朝向某个终点航向。阈值是到点判定半径，不保证实测绝对精度为 10 cm，也不等于最终制动后的精确误差。

变更已同步到 `config/jetson_system.yaml`、`agri_bringup/config/system.yaml`、多点节点/控制器缺省值及 `agri_backend/missions.py` 的参数模型。前端新建任务读取后端提供的默认值；已保存任务继续使用自己保存的值，需打开编辑页把该项改为 0.1 并保存后才对该任务生效。不要修改历史执行目录中的配置快照。该变更不调整全覆盖跟踪完成阈值和覆盖起点接近控制器显式设置的容差。

## 开始和结束原地转向

航向误差 e 是“从当前位置指向当前目标点的方向”减去“机器人当前航向”，归一化到 [-π, π]。Web 显示度，参数保存和 ROS 控制计算使用弧度。

| 参数 | 当前默认 | 行为 |
| --- | --- | --- |
| rotate_threshold | 1.0 rad ≈57.3° | 当航向误差绝对值≥该值，进入原地转向，线速度为零 |
| align_threshold | 0.2 rad ≈11.5° | 已处于原地转向时，当航向误差绝对值≤该值，结束原地转向并恢复前进 |

在两个阈值之间保持原有的转向状态：例如 30° 误差时，已经在原地转向就继续；原先在向前行驶就继续边走边纠偏。双阈值形成滞回，避免误差在一个阈值附近抖动时反复切换“走/停”。恢复前进不代表停止航向控制，仍会继续纠偏。

这组默认值是现有实现和此前试验沿用的调参值，没有通用标准或证明其为当前底盘最优值的对比实验。选择时要结合航向噪声、转向响应/超调、制动延迟、转弯空间以及“允许多大朝向误差仍向前行驶”。结束阈值应给测量噪声和转向惯性留出余量，且必须小于开始阈值；过于苛刻可能导致长时间原地修正。调整后须单独实车验证，不能仅根据此前一次任务完成就宣称最优。

## 航向和距离控制增益

航向增益 `heading_kp`（默认 1.0，单位 1/s）：

```text
angular_z = clamp(heading_kp × e, -max_angular, max_angular)
```

同样误差下，增益越大，要求的转速越大；达到最大角速度后不再增加。增益偏大可能增加过冲/摆动，偏小可能对齐慢。以 Jetson profile 的 `max_angular=0.3 rad/s` 为例，e=0.1 rad 时默认输出 0.1 rad/s，e=0.5 rad 时因限幅只输出 0.3 rad/s。原地转向和前进纠偏都使用此增益。

距离增益 `distance_kp`（默认 0.5，单位 1/s）控制接近目标时的基础线速度：

```text
base_v = clamp(distance_kp × d, min_linear, max_linear)
linear_x = base_v × max(0, cos(e))
```

原地转向或已到点时，以上前进速度被覆盖为零。车辆越接近目标，基础速度越小；增益越大，同距离下速度越大，越接近目标才开始退出最大速度饱和区。以 max_linear=0.5 m/s、min_linear=0.02 m/s、e=0 为例，d=1 m 时输出 0.5 m/s，d=0.4 m 时输出 0.2 m/s，d=0.12 m 时输出 0.06 m/s，d≤0.1 m 时直接到点停车。航向不正还会乘 cos(e) 减速，因此最终线速度可能低于 min_linear。减小到点阈值不意味着已经优化制动距离，实际停车误差仍需验证。

## 文件位置与生效

- ROS 算法：`agri_robot_ws/src/agri_waypoint/agri_waypoint/controller.py`。
- ROS 节点声明/任务开始重新加载参数：同目录 `node.py`。
- 一键启动 profile：`config/jetson_system.yaml` 的 waypoint 段；普通默认配置为 `agri_robot_ws/src/agri_bringup/config/system.yaml`。
- Web 参数校验、缺省值、默认配置读取：`agri_backend/missions.py`。
- Web 字段、单位和提示：`agri_web/src/components/tasks/taskParameters.ts`；`TaskEditor.vue` 在度与弧度之间转换并保存任务。
- Web 开始任务时把任务参数下发 ROS：`agri_backend/workspace.py`。

ROS 源码/YAML 更新后需构建相应的 agri_waypoint/agri_bringup 包，在停车状态重启加载旧代码/配置的节点；后端缺省值更新需重启后端。网页中明确保存的任务参数由开始操作下发，不能仅修改启动 YAML 就声称已有任务已经使用新值。
