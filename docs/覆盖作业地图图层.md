# 覆盖作业地图图层

适用日期：2026-11-09。位于 Web `/planning`“全覆盖规划与跟踪”的任务编辑/执行区域。

## 显示与操作

保存覆盖任务并点击“生成覆盖路径”，地图自动准备本轮图层。六个复选框可以独立显示或隐藏：

| 图层 | 显示 | 数据含义 |
| --- | --- | --- |
| 内缩轮廓 | 紫色虚线 | 按当前任务 `headland_width` 对可作业地块内缩后的边界；禁入区相应外扩，保留分裂后的各片轮廓 |
| 已完成作业区域 | 绿色 | 本轮正式跟踪期间，已观测连续轨迹扫过的区域估计 |
| 规划作业路径 | 蓝色实线 | 本轮已经核对指纹的完整参考路径，包含连接转弯 |
| 未完成区域 | 淡红色 | 地块扣除禁入区后，尚未被本轮正式轨迹覆盖的区域；包括未作业的地头 |
| 重复覆盖区域 | 橙色 | 同一位置的足迹离开后再进入，经过次数至少两次；橙色叠加在绿色上 |
| 禁入区域 | 灰色斜线 | 边界数据中的内环，不计入可作业面积，不涂覆盖色 |

默认选择“实际作业估计”。尚未正式跟踪时，未记录作业区域显示淡红色；这不代表已经测量出最终漏作面积。点击“规划预测”可以提前查看假设完整执行参考路径后的作业、漏覆盖和重复覆盖区域，界面相应更名，避免把预测当成已完成。

内缩轮廓可在编辑边界或参数的预览中查看。内缩后为空时不画虚构轮廓。内缩轮廓用于展示整块地留出地头后的边界，不额外展示规划器的单元分解辅助边线。

保留等比例缩放、拖动、复位视图、机器人位置及最近实际轨迹。地图数据与运行记录绑定；编辑未保存的边界/参数或切换任务时，旧运行图层被隐藏。地图图层开关与“规划预测”选择仅改变显示，不切换车辆模式，也不开始或恢复任务。

## 累计口径与延迟

- 坐标始终使用统一固定 UTM 原点的局部 `map` 米制坐标，不分别将轨迹归零。
- 评价幅宽优先取 `evaluation_width`，为 0 时沿用 `operation_width`。以 `base_link` 为圆盘足迹中心，半径为幅宽一半；与任务结束报告使用同一几何模型和面积网格。
- 默认请求 0.05 m 网格，可由任务 `quality_resolution` 配置；大地块自动加粗到最多 160000 格。边缘栅格通过地块及禁入区轮廓裁剪。
- 只读取本轮 `tracks/track_*.csv` 的新增完整行，接近和对齐文件不参与涂色。超过 0.5 s 的记录间隔、异常跳变、非递增时间和已收到的非跟踪状态边界切断连接，不跨空档补面积。
- 重复覆盖计算复用报告的连续足迹计次，不按相邻采样圆盘重叠或消息数量计数；静止时重复采样不会自动增加次数。
- 约每 2 s 请求一次后台快照，实际延迟还包括控制器文件刷新、运算与网络时间。每次三张区域图片成组替换；过期或失败时显示提示，不重新取得控制权。离页后停止刷新并释放图像。
- 后台增量运算在单个低优先级独立进程中执行，至多一个在途任务；HTTP 请求不执行面积计算，不创建 ROS 节点、不发布速度指令。图片缓存仅保留少量版本。
- 任务结束后，以本轮 `analysis/coverage_quality_actual_cells.csv` 核对最终区域，状态显示“已与本轮结束报告核对”。没有有效正式轨迹时显示缺少数据，不能据此声明实测覆盖率为零。迟到的状态边界可能使最终核对结果与此前的临时累计略有差异。

这里仍是假设正式跟踪时机具开启的几何估计；没有独立作业开关、幅宽标定或地面真值，不代表已经实测播种、施药等真实作用面积。具体指标分母及精度限制见 [全覆盖作业质量评价](全覆盖作业质量评价.md)。历史任务不回填；不支持的旧运行请重新生成规划。

## 接口与代码

| 接口 | 用途 |
| --- | --- |
| `GET /api/runs/{id}/coverage-map` | 本轮轮廓、地图范围、版本、来源状态及最近正式轨迹；首次返回 `PENDING` |
| `GET /api/runs/{id}/coverage-map/{planned或actual}/{completed或remaining或overlap}.png?v={版本}` | 对应版本的透明 PNG；版本未缓存则返回 404，等待地图刷新 |
| `POST /api/missions/preview` | 预览边界与内缩轮廓，不启动规划或运动 |

主要文件：

- `agri_web/src/components/dashboard/FieldMap.vue`：六图层、图例、裁剪与米制叠加。
- `agri_web/src/composables/useCoverageLayers.ts`：任务/坐标校验、快照更新、图像成组替换与资源释放。
- `agri_backend/coverage_map.py`：轨迹增量读取、图层生成、最终报告核对与缓存。
- `agri_backend/coverage_geometry.py`：与报告共用的足迹及计次模型。
- `agri_backend/missions.py`：预览内缩轮廓。

本次仅涉及前后端；已启动的后端需要在任务结束且车辆停止后重新加载，网页刷新后读取新代码。生产前端需重新 `npm run build`。不需要为此重编 ROS 功能包，不需要重启底盘、雷达或定位驱动。
