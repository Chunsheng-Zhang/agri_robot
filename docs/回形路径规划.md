# 回形路径规划：从内向外连续展开

2026-11-10更新。按用户Figure_1示例，“回形”（`CONTOUR`）是一条从内向外连续展开的开口绕行线，替代原来的“闭合每圈后再串联”。牛耕、蛇形和原来的螺旋条带排序保持原行为及缺省值。

## 使用

1. 选择或创建覆盖任务，选择“回形”。
2. 核对作业幅宽、地头预留宽度、最小转弯半径、转弯曲率形式及采样间距，保存任务。
3. 点击原“生成覆盖路径”，等待规划与质量评价完成。
4. 地图绿色起点位于最内侧可行层，沿一条路径向外展开，红色终点位于最外层；按参考O形的边线交点连续向外递进，不返回本层起点闭环。规划不自动开始行驶。
5. 正式执行继续使用原来的明确开始、接近首点、航向对齐和Pure Pursuit流程。直达内部起点的接近过程不提供跨地块绕障，应独立确认通道可行。

不改写旧任务和历史实验。旧保存路径仍是旧几何，需要重新生成并保存，才能使用连续回形；不自动将牛耕任务改成回形。内外方向保持从内向外。

## 参数含义

| 参数 | 回形中的用途 |
| --- | --- |
| `operation_width` | 相邻轮廓的偏置间距 |
| `headland_width` | 继续保留原人工设置的外侧预留区；本次未加入自动宽度选择 |
| `robot_width` | 与原规划相同的保守圆形车体净空检查 |
| `min_turning_radius` | 圆角及层间连接的最小半径约束 |
| `linear_curv_change` | 连续曲率模式的曲率变化约束，Web规划从coverage_server读取并同步到适配器 |
| `path_continuity` | 最新统一选择Fields2Cover四种原生曲线，圆角/连接直接调用生成器；旧CONTINUOUS/DISCONTINUOUS映射到DubinsCC/Dubins |
| `allow_reverse` | 默认false；勾选时Reeds–Shepp/HC层间连接可包含倒车，圆角保持前进绕行 |
| `sampling_distance` | 请求采样间距；曲线内部进一步细采样到不大于半径的0.08倍，以降低折线弦误差 |
| `swath_angle` / `angle_mode` | 用于原平行条带模式，回形跟随地块轮廓，不按这两个参数旋转条带 |
| `evaluation_width` / `quality_resolution` | 沿用独立质量评估配置，不改变规划路径 |

最外侧中心线偏置为 `headland_width + max(operation_width/2, robot_width/2 + 0.00001)`。因此回形也保留地头预留区，不能将其结果自动解释为已覆盖整个地块边缘。设地头为0仍须满足车体净空和圆角要求。

## 几何与运行流程

- 由原始多边形逐层内缩，间距采用作业幅宽；不修改固定UTM原点，不将地块或轨迹分别归零。
- 对轮廓生成平滑圆角，剔除不能容纳规定半径/曲率过渡或净空不足的轮廓。
- 按内缩深度从大到小依次访问，第一点位于最内侧可行轮廓，不保证位于几何中心；全部候选都容纳不下时明确失败。
- 无孔洞且逐层内缩保持单连通的地块（含轻微凹地块）按参考`Coordinateself.loop/intersection_points`的O形点序构造：本层依次经过各边，末端取“本层首边与下一层末边”的交点，沿下一层末边继续，随后重复内缩。整条点序反转为由内向外，再统一对连续折线转角调用Fields2Cover平滑；不会先闭合一圈再另加横移连接。最内层以参考逻辑的终止边起步，容纳不了转角约束时舍弃更深层重试；若原本有多层而连续连接只能退到最外一层，则明确失败，不能把单层代替整条回形。原本就只能容纳一层时保留开放轮廓边。
- 使用向量直线求交替代参考代码的斜率公式，支持竖直边，沿用原多边形偏置与固定原点。参考样例在同一外层偏置下，未平滑顶点与原O形对应点差小于1e-8 m；原参考从外向内，本项目反转为从内向外。平滑后点数、角点位置与原尖角折线不同。
- 对此类单连通地块检查整条回形线不得自交，不可行时明确失败，不退回旧闭环串联。直线采样的终点直接复用下一段原生端点，避免UTM往返中的微小舍入造成假自交。曲线切入、出口及相邻层航向连续；不会为模仿图中的尖角而去掉最小半径约束。
- 禁入环及内缩后分裂超出单一O形绕行的适用范围，使用通用开放轮廓/直线接缝和原生曲线逐一安全连接，并标记`BRANCHED_OPEN_CONTOURS`；此时可能存在分支、交叉或绕障连接，不能保证为单一同心回形。复杂地块可能无法连续连接，此时返回原因，不跨禁入区、不发布断开的局部路径。
- 连续曲率圆角用空间估计确定切入距离，再直接调用Fields2Cover选定生成器并检查端姿态、圆角区域和净空；浅凹角的原生CC曲线可能需要比估计更长的入弯段，此时仅有界增加该角的切入长度，再检查相邻圆角不得重叠，不降低最小半径或曲率变化约束；不再将自定义Bezier作为执行曲线。数值可行性筛选不是独立实车运动学验证。
- 原Fields2Cover转弯缓存按毫米/毫弧度量化，可能混淆相近但不完全相同的角点；本模式关闭此缓存，严格检查连接终点和航向。
- 最终路径沿用原`validate_path`：保守圆形车体全路径净空校验、map frame、固定原点、局部距离上限；默认拒绝倒车，勾选后保留车体航向与方向供分段跟踪，详见[原生曲线与倒车跟踪](Fields2Cover原生曲线与倒车跟踪.md)。
- 回形计算在单个低优先级spawn子进程中运行，ROS状态/安全回调保持处理；有超时、500层、2000轮廓、150000路径点预算及协作取消。取消、超时、模式/原点变化后不发布迟到结果或部分文件。

起步和圈间连接会产生重叠，圆角、较大半径及无法容纳更小轮廓的中心也可能留下漏覆盖区。人工回形本身不包含专门的中心补作；后续已另行增加一键优化、自动地头宽度和转弯候选库，见 [一键优化规划与转弯候选库](一键优化规划与转弯候选库.md)。真实作业质量仍由完整路径足迹、统一分母和已有报告计算，不能声称100%覆盖。

## 数据与代码

本轮 `paths/coverage_*.json` 沿用原位置、`frame_id`、`projection`、`points`、`velocities`、`is_backward`。新增 `planning` 字段包含：

- `mode=CONTOUR`、`direction=INSIDE_OUT`。
- `ordering=REFERENCE_O_REVERSED`及`raw_spiral_vertices`保留反转后的平滑前O形顶点；复杂地块标记`BRANCHED_OPEN_CONTOURS`。
- `topology=OPEN_SPIRAL`、`closed_laps=false`；旧保存结果没有这两个字段，不能据此认定旧几何已更新。
- 每层深度、偏置距离、内外环类型、起止点索引；索引对应最终去重后的 `points`。
- 每层`closed=false`、开口距离，以及`connections`中的入口/出口索引、相邻层编号和原生曲线模型；连接起止索引与相邻绕行段严格对应，便于复核连续性。
- 圆角/连接模型、实际采样间距、轮廓数及被拒绝的轮廓原因。

ROS接口仍为 `/planning/plan`、`/planning/cancel`、`/planning/status`、`/reference_path`，覆盖质量评价、地图图层和后续跟踪共用同一条选定路径。

主要实现：`agri_robot_ws/src/agri_path_planning/agri_path_planning/contour.py`、同包 `node.py`；Web字段在 `agri_web/src/components/tasks/taskParameters.ts`，后端校验/下发在 `agri_backend/missions.py`、`workspace.py`。
