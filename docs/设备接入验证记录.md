### 相机网页黑屏修复

用户通过 `http://10.111.61.38:5173/` 访问时黑屏。对比网页实际地址后发现：后端 `urlencode` 把话题分隔符 `/` 编为 `%2F`，当前原厂视频服务直接将 query 值作为 ROS 话题，未执行百分号解码。含 `topic=%2Fcamera%2Fcolor%2Fimage_raw` 的请求虽然返回 HTTP 200，但响应只有 22 字节的 multipart 边界，不含 JPEG；`topic=/camera/color/image_raw` 正常输出画面。此前只验证了手写的未编码地址，因此没有覆盖网页真实请求。

修复 `agri_backend/devices.py`，生成视频地址时保留 `/`，其余 query 值继续编码。HTTP 回归增加原厂话题格式检查；`tests/test_ros_video.py` 改为使用后端实际返回的 query，避免测试与网页各自拼出不同地址。只平滑重启 FastAPI 后端，相机、视频、ROS 核心和底盘驱动未重启。修复后通过用户实际 IP 获取 `/api/camera/stream-info`，原样使用返回地址及网页 `_connect` 参数，经 5173 代理取得并解码完整 640×480 JPEG；样帧为 `.diagnostics/camera-fixed.jpg`。离线回归仍为 61 passed、10 skipped。最终复核时发现急停已被解除但输出仍为零，随即调用现有急停接口重新锁定，并确认状态新鲜、控制权为空、三个速度输出均为零；未发送解除急停或运动命令。
