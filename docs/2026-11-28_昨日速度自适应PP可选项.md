# 昨日速度自适应PP可选项

2026-11-28，用户要求保留当前速度/曲率自适应PP，并将11月27日实车使用的仅速度自适应PP作为额外选项。它是路径跟踪控制器，不是覆盖路径规划器，不改变规划几何。

覆盖与独立路径跟随算法列表如下；已按用户后续授权加载运行服务，见文末部署状态：

| 网页选项 | 标识 | 前视规则 |
| --- | --- | --- |
| PP（速度/曲率自适应，GA参数） | pp | clip((L0+0.8388×abs(v))/(1+0.4076×abs(kappa)),0.65,1.05) |
| PP（仅速度自适应，昨日版） | pp_speed | L0+0.35×abs(v)，不使用曲率项或上述截断 |
| Stanley / LQR / MPC | stanley / lqr / mpc | 原有实现 |

昨日版参数来自11月27日09:01、09:25实车归档及Git中加入曲率前的实现。虚拟轴距0.16m、后轴偏移0、虚拟转角上限35°与昨日一致。速度反馈仍来自MGX23生成的里程计纵向速度；目标选点仍限定当前行驶分段，保留倒车/停车转向状态机及当前安全检查。

## 网页操作

1. 覆盖页在任务空闲时选择“PP（仅速度自适应，昨日版）”，基础前视建议值随明确选择设为0.8m；选回GA版则建议0.5590m，可再自行修改。只改草稿，不立即改实车控制器。保存任务、重新生成覆盖路径，再明确开始。
2. 独立路径跟随在空闲时选择同名选项，核对基础前视、速度和角速度，再按既有加载/开始流程执行。
3. 已保存任务重新打开时保留其参数，不因页面读取而重置L0。API选择pp_speed且省略lookahead时默认0.8，显式提供的值优先。
4. 选择不会自动修改速度、角速度上限或安全策略；上限继续按用户最近要求允许±5rad/s。昨天两轮的任务速度0.5m/s、L0=0.8m、角速度上限1rad/s，选择控制律本身不代表完整实验条件与昨天相同。

缺省选择仍为当前GA版PP。运行、申请控制权或暂停期间不能切换；暂停后继续沿用原控制器。用户提出“增加供选择”，本次不自动改选已有覆盖任务，也不重新规划或开始行驶。

新实验config/tracking_controller.json和轨迹侧文件分别记录算法pp_speed、实现agri_path_tracking.pp_speed_only.20261127及四项实际固定系数；GA版仍保持原实现标识与参数组。实际L0以任务配置为准，历史实验保持原样。
