# 原地转向智能规划

更新：2026-11-15。当前为三类布局统一比较的v7“一键优化规划”，保留v6沿边搜索并增加原生整田不分解与分区独立方向。手工“生成覆盖路径”继续保留；原生曲线与回形路径不因此重写。升级与10地块验证见[三类布局升级](2026-11-15_三类布局一键规划升级与10地块验证.md)。

## 使用

1. 在 Web“全覆盖规划与跟踪”选择或新建任务，编辑边界与禁入区。
2. 在“规划与路径跟踪参数”填写机具有效作业宽度、车体包络长宽和原地转向安全余量，按需要设置跟踪速度及前视距离。
3. 点击“保存任务”，选择“全覆盖作业”模式，点击“一键优化规划”。规划本身不会取得运动控制权。
4. 查看推荐方向、最小安全地头、总长度、覆盖率、重复覆盖率、原地转向点数及候选评分；地图的内缩线与报告采用本轮自动地头。
5. 如需以后复用，明确点击“保存规划路径”，才会进入左侧任务下的路径列表。“加载此路径”与“前往起点并开始覆盖”仍是两个独立操作。

智能策略的手工输入集中在物理参数与跟踪参数。条带顺序、人工方向、人工地头、最小转弯半径、四种原生曲线和允许倒车，继续服务于手工“生成覆盖路径”；一键优化不读取这些选项，固定前进直线＋停车原地转向。任务中保留这些参数便于两种按钮分别使用。

## 几何与最小安全地头

用户确认先沿用估计值并保留修改入口：

| 参数 | 初值 | 修改位置 |
| --- | ---: | --- |
| `operation_width` | 沿用本任务 | Web“机具有效作业宽度”，单位m |
| `robot_length` | 0.45 m | Web“车体包络长度” |
| `robot_width` | 0.2 m | Web“车体宽度 robot_width” |
| `rotation_safety_margin` | 0.05 m | Web“原地转向安全余量” |
| `rotation_center_x/y` | 0 / 0 m | 任务JSON或统一YAML，按base_link到包络中心的偏移配置 |

L/W应包住车辆及随车机具实际外伸；有效作业宽度与物理包络宽度含义不同。base_link的旋转中心默认在矩形中心。规划不根据当前RTK定位漂移自动修改车辆尺寸。

```text
r = hypot(L/2 + abs(cx), W/2 + abs(cy)) + safety_margin
headland = r + 0.0001 m
```

缺省r约0.296221 m，地头约0.296321 m。0.0001 m是几何运算数值裕量，不是定位精度承诺。这个宽度是当前完整圆包络模型的安全内缩值，不是任意安装方向、机具姿态下经过证明的实际最优地头。

地块外边界向内缩、禁入区向外扩。2026-11-14起智能工作区采用保守的mitre折角偏置，避免沿离散圆角不断停车旋转；最终仍使用完整圆包络检查，不降低净空。沿所有行驶段与转向点使用同一个完整圆包络检查，比只在转角检查更保守；因此某些窄区即使直行能通过，也可能在本策略下不可行。若内缩区域分裂且无法安全连接，整轮失败，不穿越禁入区或把不完整路径当成功。

作业幅宽大于车体包络时，圆盘评价足迹可能覆盖到中心线不能到达的边角，但不代表机具没有实体尺寸；物理机具仍应体现在长宽包络中。尺寸与余量必须在实车实验前核对，变化后保存任务、重新规划。

统一缺省配置仍为`agri_robot_ws/src/agri_bringup/config/system.yaml`及`config/jetson_system.yaml`。新任务可继承缺省，任务级值优先并随运行归档；旧任务/实验快照不回写。雷达独立车体尺寸配置不由此自动改变。

## 原生分解、TSP路由与有限角度搜索

当前使用本机既有Fields2Cover 2.0，先完成下述沿边统一方向候选，再加入原生整田和分区独立方向候选。以下1–3描述沿边子策略，不是全部候选都必须采用统一方向：

1. 对每个作业方向，将安全工作区旋转到条带水平的局部计算坐标，按1微米数值精度稳定几何；不修改原始经纬度、固定原点或历史文件。
2. 调用原生`DECOMP_Boustrophedon`，检查每个分区扫描单调、无孔且并集完整。检查失败则尝试原生`DECOMP_TrapezoidalDecomp`，仍失败就拒绝该方向。
3. 当前一键策略以每条有效外边界/孔洞边绑定平行方向和向可作业侧半幅宽的起排位置，中间保持机具幅宽间距，向两侧铺满全部分区；比较原布局与正增益补边集合，不独立搜索偏移、不均分所有间距。通过Fields2Cover原生`Swaths.append`把扫描线裁剪到上述安全分区，组织为`SwathsByCells`并赋全局唯一编号。窄分区若恰好落在全局扫描线之间，保留一条原生裁剪的中线，不遗漏分区。
4. 调用原生`RP_RoutePlannerBase.genRoute`，由库内部OR-Tools TSP求全部作业行的访问顺序和朝向。允许跨分区作业，也允许再次进入分区，不再采用项目自己的分区块2-opt或四状态DP。
5. 完整读取原生`Route`的作业行和`getConnection`连接。缺行、重复访问作业行、端点不一致、连接空档都拒绝；不以直线替换原生连接。合理通道重走仍可出现，不能承诺所有线条绝无交叉。
6. 对完整折线重采样，在折点插入同XY不同航向的停车转向标记，按原完整车辆旋转圆包络检查。这里不调用Dubins/Reeds–Shepp曲线；正常行进为前进，点序反转不是倒车。
7. 完成沿边方向搜索后，加入下述原生布局候选，使用相同的步骤4–6和固定评分选择完整可执行方案。

首轮方向包括原始各条有效边方向、边界PCA主方向、垂直方向及0–165°的15°网格，角度以map东向为0、逆时针为正，按180°周期处理。再围绕当前较优方向比较±5°、±2°、±0.5°。同方向复用分解；方向与排线都等价时不重复计算原生路由，不仅按角度合并平行边；不因候选数或45秒主动截断，保留所有候选评分和最佳完整几何。

新增两类原生布局：

- `NATIVE_WHOLE_FIELD`：安全区保持一个含孔多边形，不先分解；分别用`NSwath`、`NSwathModified`、`SwathLength`，按原生1°步长搜索作业方向并裁剪作业行。
- `NATIVE_PER_CELL`：分别比较BCD与梯形的0°/90°分解，共4种分区。每种分区、每个条带目标由原生`generateBestSwaths`独立寻找各区方向，再把全部作业行交给同一个TSP。分区只切分安全区，不对每条虚拟切线额外内缩地头。

新增布局同时比较原生自动和guided local search两种路由设置，各1秒；最多15种条带布局、30次完整路由设置，几何不可行及完全相同的同类作业图会拒绝或去重。它们是预定算法组合，不是对整个搜索设置候选数量上限。各区空条带时不悄悄漏区；拒绝该原生布局，原沿边窄区保留行候选仍能参加。

未设置人工入口时，沿边布局评价一条自由开放路线；新增布局对上述两种TSP设置分别评价。设置入口时，每种路由设置均比较自由路线的两个起端，以及原生入口引导路线的两个起端（最多四种）。本地2.x只提供相同起终点的入口接口，因此入口引导种子先由原生生成闭环，再仅去掉入口接近和返程连接，保留全部作业行及其间连接；不能把它说成精确的“固定入口开放TSP最优解”。入口锚点碰巧与作业图节点重合时拒绝该入口种子，继续比较自由路线，不擅自挪入口。

不同分区方向记录在`cell_directions`，`direction_mode=PER_CELL`时网页显示“各分区独立”及各区角度，不把兼容字段`angle_rad`冒充全局方向。该字段只保留最长作业分区的代表方向。

**完整角度搜索不等于穷举全部行顺序。** 每次原生TSP调用沿用库的1秒启发式求解设置，不求最优性证明；有入口时同一套排线可能调用两次。项目外层按覆盖/重复/长度/转弯次数0.40/0.25/0.20/0.15评价各完整方案，库内部路由仍以连接/行驶代价安排顺序，不是直接对四个目标做精确联合求解，也不是PSO/NSGA/HANS。

网页进度显示准备、粗搜、细化、原生布局比较和最终校验阶段，以及阶段进度、候选数/可执行数和用时。`search_complete:true`表示预定布局及方向评价已完成，不表示TSP排列已穷举；候选编号数量随方向去重、入口和不可行情况变化，不固定为20。

保留“取消规划”及`planning_timeout`异常保护（缺省120秒）。智能搜索将该时限用于无新进度看门狗，持续有效进度可超过120秒总时长；旧token、重复源进度和超时后的迟到结果不能续期。手工规划仍保留原总时限，取消或超时不发布部分较优结果。原生调用期间不能逐节点中断，工作进程返回后仍检查取消标记。每轮状态包含接收请求时快照的`request_id`，后端只接收本轮状态，避免上一轮迟到失败覆盖下一轮。

独立资源保护仍存在：最多1500条作业行；原生全点对通道图按“条带端点＋分区边界角点”估计规模，超过768拒绝该方向，防止Jetson内存耗尽。这是单次几何规模保护，不是候选数量上限，不会把部分路径当作完整结果。采样点数、评价网格等原有预算也继续生效。

## 评分与质量口径

令A为整田面积（扣除禁入区，包含地头），W为用户机具有效幅宽，L为完整平移路径长度，C/O为覆盖率/重复覆盖率的百分数：

```text
L0 = A / W
N0 = max(1, 2 × sqrt(A) / W)
J = 0.40 × (1 − C/100)
  + 0.25 × O/100
  + 0.20 × L/(L + L0)
  + 0.15 × N/(N + N0)
```

选J最低的可执行完整方案；同分依次优先覆盖率较高、长度较短者。N为最终完整执行路径的停车转向标记数量，不含接近与首次对齐，包含换行及绕障拐角；归一化参考N0在同一地块/幅宽的所有候选间固定。C、O、长度及转弯代价均为无量纲项，权重固定，界面不再让用户编辑多套策略权重。没有最低覆盖率硬门槛。

C为至少经过一次的面积/A，O为至少经过两次的面积/A。不是“多走长度比例”，也不是“重复面积/已覆盖面积”。漏覆盖按同一整田分母计算；地头单列统计。所有候选采用相同圆盘等效机具足迹和同一网格，输入`quality_resolution`默认0.05 m，大地块超过网格单元预算会自动加粗并记录实际间距。候选评分与最终报告使用同一实际网格。

智能规划的条带间距与评价幅宽均使用W，不自动改幅宽，不再单设第二个评价幅宽输入。历史手工任务若有`evaluation_width`仍按旧口径只读/执行；新智能规划明确忽略它，并标注`width_source=operation_width_effective`。

L包含全部作业行、换行及绕已知禁入区的连接；设置人工入口时另包含入口参考连接距离，其田外部分仍是未验证示意。停车原地转向的平移长度为0；执行时的单点接近仍独立，不因设置入口而先经过入口。此版不优化能源、作业时间或土壤影响。所有平移连接都按机具开启估计，当前没有真实机具开关数据，不将几何覆盖率称作实测农艺作业质量；圆盘模型也不增加原地旋转的独立作业面积或重复次数。

## 跟踪、暂停和数据

ROS接口保持`/reference_path`（`nav_msgs/msg/Path`、map坐标）。规划进度经独立后台进程传至`/planning/status.search_progress`，每0.2秒随状态心跳发布，网页复用`/api/devices`刷新，不另建运动通道。原地转向标记为相邻两个相同XY、不同入/出航向的Pose；保存文件中保留这些Pose与`motion_signature`，不能在其他工具中随意去重。跟踪器读取标记，将路径拆为独立直线段，进度投影与前视点不会跨过未完成的原地转向点。

1. Pure Pursuit沿当前直线段前进，接近段尾减速。
2. 中间段在剩余长度和端点距离均进入`min(0.05 m, completion_tolerance, 当前段长/4)`后输出零速度、切到下一段的ALIGNING。
3. 保持零线速度/零角速度，使用新鲜定位检查约0.5秒的位置稳定，漂移超过2 cm重新计时。
4. 线速度持续为0，按下一段航向原地旋转；默认角速度不超过0.3 rad/s，同时受任务上限约束。
5. 航向误差进入±10°、新鲜定位保持约0.5秒且位置稳定后，进入下一段前进。对齐超时30秒故障停车。

这些稳定性检查来源于定位，不等于独立轮速反馈证明物理停稳。暂停/继续保留段号和进度，并重新对齐；停车等待阶段恢复会重新计时。急停、定位故障、控制权及速度安全检查仍由现有链路处理，不自动恢复。多点导航逻辑不变。

```text
data/experiments/<本轮>/
  config/mission.json                  人工幅宽、车辆尺寸、余量及任务快照
  paths/coverage_*.json                完整入/出航向、转向标记、旋转包络、有效参数、姿态指纹
  paths/optimization.json              schema_version=3，沿边/补边候选、四目标权重、贡献及拒绝原因
  tracks/track_*.csv/.json             正式平移跟踪，元数据包含point_turn_indices
  tracks/alignment_*.csv/.json         起点/中间原地转向/恢复对齐的独立记录
  analysis/coverage_quality_plan.json  本轮规划预测，统一有效幅宽与安全地头
  analysis/coverage_quality_report.md  结束后的作业质量、规划规则与本轮跟踪汇总
  analysis/planning_objectives.csv     四目标原始值、归一化代价、权重与评分贡献
```

`paths/optimization.json`仍通过`GET /api/runs/{id}/optimization`查看，独立优化接口仍为`POST /api/missions/{id}/optimize`及ROS`/planning/optimize`（Trigger）。保存、加载检查相同任务版本、固定原点、完整旋转净空和姿态指纹；修改尺寸、余量或幅宽需重新规划。历史v1优化报告保留原解释，不改写既有路径及实验数据。
