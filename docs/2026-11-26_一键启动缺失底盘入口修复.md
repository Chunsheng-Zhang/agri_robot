# 一键启动缺失底盘入口的检查

此前一键启动时，核心实际安装目录缺少源码已有的 `yahboom_driver_monitor` 入口，核心先退出，随后后端急停确认失败、启动脚本清理本次进程。源码存在及 `install/setup.bash` 存在，都不能证明 ROS 实际找到的安装入口齐全。

`scripts/project.py` 现在在创建服务之前，通过 ament 查询实际包前缀，检查核心各包的控制入口是否存在且可执行。缺少包、缺少入口或入口没有执行权限时，直接报告具体包/路径，不先启动半套服务。

停车且任务空闲后，加载项目环境、重新构建缺失入口所属的项目包，再使用原入口：

```bash
cd /home/jetson/agri_robot
source scripts/setup_environment.bash
cd agri_robot_ws
colcon build --packages-select agri_base --symlink-install
cd ..
bash scripts/project.bash start
```

将构建包名换成实际报错的项目包；不修改厂商工作区或更新系统依赖。此处命令是修复说明，本次 Git 整理没有执行构建、启动或实车运动。

预检测试使用临时安装目录模拟正常入口、包不存在、入口缺失及不可执行四种情况，不启动 ROS 节点或硬件。此前实际安装恢复及静态启动验证见根目录 `AGENTS.md` 的历史记录；本次仅复核软件行为。
