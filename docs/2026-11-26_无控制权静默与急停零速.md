# 无控制权静默与急停零速

2026-11-26，用户要求项目无控制权时不持续下发零速，并补充“急停状态下持续发布0速”。用户已确认SBUS摇杆回中、车辆停稳，允许软件测试后加载新版。

## 行为

修改`agri_robot_ws/src/agri_base/agri_base/chassis_adapter.py`，不修改MCU固件、原厂驱动、PID或既有任务速度。

| 状态 | 向底盘驱动的输出 |
| --- | --- |
| 无控制权、安全消息小于0.3秒、无急停/运动禁止/障碍锁定，且两级发布者唯一 | 进入该状态时发送一次零速，之后静默 |
| 急停，即使无控制权 | 持续零速 |
| 运动禁止、障碍锁定、安全状态未收到/超过0.3秒，或指令发布者缺失/冲突 | 持续零速 |
| 持有控制权、允许运动，且指令小于0.25秒 | 按原规则转发有限数值指令及允许的横向速度 |
| 持有控制权但指令超时或数值无效 | 保留零速停车检查 |
| 控制权切换、节点正常退出 | 清理旧目标并发送零速；新权限需新指令 |

这里只改变`/base/driver_cmd_vel`的发布行为，原厂驱动不再因正常空闲而反复接到零速串口命令；safety仍持续发布`/cmd_vel`和状态，监控/数据采集继续工作。未增加Web开关，不自动获取权限或判断SBUS是否在驾驶。

SBUS仍直接进入MCU。用户已接受网页急停和雷达停车不能可靠约束SBUS：串口零速可被后续SBUS指令覆盖，持续零速也不等于MCU级锁存急停或互斥仲裁。该限制没有因本次修改而消除。正常静默时，项目不再持续向SBUS写入刹车命令。
