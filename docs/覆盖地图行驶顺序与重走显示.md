# 覆盖地图：行驶顺序、作业行序号与重走标红

更新：2026-11-15。入口为Web“全覆盖规划与跟踪”下方的“覆盖作业地图”。

## 显示规则

- 规划路径按执行先后由紫、蓝、青、绿到黄渐变，图例显示“先→后”；配色依据参考路径的顺序，不随地图方向、当前位置或完成进度重新排序。
- 作业行按规划器保存的真实访问顺序从1编号，标签放在行中点。使用`swath_visits`和`native_route_connections`核对整条参考路径，不按条带ID或空间坐标排序；换行、绕障连接和原地转向不单独编号。
- 同一中心线路段被再次经过时，该重合部分用红线覆盖。往返都算，局部重合只标局部；普通交叉点和两条临近路径的机具面积重叠不等于重走中心线。数值识别精度为10微米，与本轮离线PDF拓扑评价一致。
- 起点仍为绿色圆点，终点仍为红色圆点，保留文字。机器人位置、实际轨迹、入口和原有区域图层沿用各自的数据来源。
- 新增“作业行访问序号”“重走路径”两个独立显示开关，默认开启；关闭“规划作业路径”会同时隐藏其颜色、序号和重走线。图层切换不控制车辆。
- 行数较多时按固定访问编号抽稀显示，放大可显示更多序号，不把剩余标签重新编号。标签带白色描边。

新生成的一键规划和已有的原生TSP规划，只要文件中保留上述元数据，就能显示真实序号，不要求重新规划或改写历史文件。没有保存可核对作业行信息的手工曲线、回形或历史文件，仍显示顺序色和可识别的重走线，明确提示序号不可用，不把每段直线臆造为作业行。回形也不人为编造往复式作业行。

红线的显示只表达计划中心线重走，不代表已实际行驶、碰撞检测或机具真实重复作业。原有实际/预测区域切换、参考路径指纹和固定坐标原点校验继续生效。

## 代码与接口

| 文件 | 用途 |
| --- | --- |
| `agri_web/src/components/dashboard/FieldMap.vue` | 渐变路径、序号、红线、开关和图例 |
| `agri_web/src/components/dashboard/pathSequence.ts` | 有界数量的顺序色带；保留转折和反向，去除直线密集采样及静止重复点 |
| `agri_backend/coverage_path_order.py` | 从原生元数据提取真实访问行，顺序核对采样路径，计算重复中心线的唯一几何 |
| `agri_backend/coverage_map.py` | 当前运行的区域快照增加`path_order` |
| `agri_backend/workspace.py` | 已保存路径预览也返回相同`path_order` |

新增内容通过已有`GET /api/runs/{id}/coverage-map`和`GET /api/missions/{id}/plans/{plan_id}/path`返回，不另增加轮询请求。父快照继续带`frame_id`、固定原点和参考路径指纹；前端只给匹配路径叠加序号/红线。

`path_order`包含`state`、`rows[{visit,start,end}]`、`retracing_state`和`retraced_lines`。工作行信息异常只禁用编号；独立的重走识别仍可使用原始路径。显示分析保留12000段/200000候选比较的保护，超限明确提示无法完整识别，不把未知写成“没有重走”；这些显示保护不改变生产规划搜索或执行路径。

顺序渐变最多96组SVG折线。直线采样仅在显示副本上压缩；稳定的路径指纹和投影范围复用已有显示结果，定位轮询不反复重建颜色几何。原始规划路径和控制参数不变。
