# 前方 180° 雷达保护与静态验证

日期：2026-10-30（Asia/Shanghai）。本次修改和验证不启动车辆运动，不解除急停，不自动恢复任务。

本文记录首次裁剪前方 180°、仍使用旧 50% 回波门槛时的实验。用户随后明确要求取消该门槛并采用 2% 障碍占比停车，现行规则与验证见 [雷达障碍占比停车逻辑与验证](2026-10-30_雷达障碍占比停车逻辑与验证.md)。下文旧门槛和“有效回波不足”的结果仅描述当时阶段，不作为当前运行要求。

## 现场情况与用户确认

用户报告：侧后方有两个直径约 6 mm 的车体细柱，后方也有车体遮挡，现场无法调整；正前方 180° 无遮挡，约 1.5 m 的目标保持原位。用户明确选择：允许正常导航和转向，仅检测前方，接受后方及侧后方没有雷达保护。

此前多点实验 `20261030_102348_690824_web_78f26a84` 因 `Motion sector unknown` 停车；后续急停使任务成为 FAULT。本次不重新开始该任务。

## 实现与配置

`agri_safety/obstacles.py` 增加 `front_only`，安全节点以只读参数 `lidar_front_only` 配置；`config/jetson_system.yaml` 和 `agri_robot_ws/src/agri_bringup/config/system.yaml` 均设为 true。类和节点自身缺省保留全向策略，兼容其他配置和既有测试。

范围以车头方向为 0°、雷达位置为起点，保留 -90° 至 +90°，应用安装偏航角 `laser_yaw`。原始 `/scan` 不变，厂商驱动不改动。范围外射线在安全几何中排除，不能视为自由空间，也不参与有效比例。前方显示角度同步为 ±90°，后方有效性为 false。

前进仍检查车体运动走廊，转向检查已观测前半圈中的车体旋转包络。允许倒车、横移和转向，不要求后半圈扫描有效，也不检测范围外障碍。因此后方与侧后方没有保护，导航算法本身也没有因此获得绕障能力。即使倒车，前方扫描无效仍会阻止运动。

保留原有阈值：有效回波比例至少 50%、角度覆盖比例至少 85%、扫描超时 0.5 s、停车净空 0.8 m、恢复净空 1.2 m 持续 1 s；解除障碍停车和恢复任务仍需明确操作。停车距离以车体净空计算，不能把雷达量程直接当作车头到障碍的净空。

50% 来源于项目安全模块既有软件配置 `min_valid_fraction: 0.5`（提交 `b3df48c` 已包含），并非用户要求或由设备报告的合格标准。这里统计的是“得到有限、在量程内距离值的射线占比”，不是已证实的硬件健康度。在空旷场地，缺少可测目标也可能使此比例较低，不能据此认定雷达故障；该阈值对现场的适用性尚未验证。本轮仅保留已有配置，并未证明 50% 是合理门槛。

`/safety/status.lidar_front_only` 和 `/safety/obstacles.front_only` 报告实际范围。Web 显示“仅检测车头前方 180°”及后方“未检测”；最近距离标注为“检测范围内最近”。雷达保护复选框默认关闭的开机约定保持不变。

## 静态采集与离线回放

在软件急停为 true、控制权为空、输出三轴为零时，只订阅 `/scan`，采集 20 帧，并在前后读取 `GET /api/devices`。使用 `rclpy` 的 sensor-data QoS，未向真实 Domain 发布任何模拟数据或运动消息。

本机诊断文件（不纳入普通 Git 提交）：

- `.diagnostics/waypoint_pause/front_180_static.json`：20 帧完整 ranges、几何元数据、前后设备状态和前方目标统计。
- `.diagnostics/waypoint_pause/front_180_replay.json`：使用本次 `ScanGeometry(front_only=True)` 离线回放的结果。
- `.diagnostics/waypoint_pause/support_posts.json`：此前侧后方近回波分布及完整扫描。
- `.diagnostics/waypoint_pause/static_target.json`、`static_target_analysis.json`、`static_target_plot.png`：早一轮目标检测数据与示意图。

此次 20 帧结果：

| 项目 | 结果 |
| --- | --- |
| 前方目标检出 | 20/20 帧 |
| 每帧目标回波中位数范围 | 1.526–1.529 m |
| 前方 180° 有效回波比例 | 16.83%–22.97% |
| 裁剪后小于 0.4 m 的回波 | 各帧均为 0 |
| 满足前进扫描有效条件 | 0/20 帧 |
| 满足带转向前进扫描有效条件 | 0/20 帧 |

结论：前方 180° 裁剪可排除这批数据中的侧后方车体近回波；目标检测正常，但前方有效回波不足的问题仍存在，不能宣称已经允许车辆正常运动。目标位置为人工约放，以上数据不构成量程精度标定。

厂商驱动将多种缺测和无效回波表示为零，不能仅凭零值判断是空旷、超量程还是扫描失效。本次不将零值改成自由空间，不降低有效比例阈值。仍需进一步查清驱动缺测语义和实际扫描质量，才能验证前进接近障碍停车。
