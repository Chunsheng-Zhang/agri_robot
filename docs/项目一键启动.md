# Jetson 项目一键启动

适用于当前 Jetson、X3 底盘、MGX23、手柄、4ROS 雷达、Astra 相机及 Web 界面。无需每次打开三个终端，也无需重复安装依赖或构建。脚本使用现有环境，不修改系统或工作区外文件。

## 每次开机后启动

在 Jetson 任意目录执行：

```bash
bash /home/jetson/agri_robot/scripts/project.bash start
```

省略 `start` 也可以。脚本自动加载 ROS 环境，并后台启动机器人核心、后端和前端；就绪后打印浏览器访问地址并返回终端，可以关闭该终端。保持 Jetson 正常运行即可。

启动配置为 [config/jetson_system.yaml](../config/jetson_system.yaml)，核心与后端使用同一份配置。它沿用 2026-10-30 当前实车参数，不依赖 `data/experiments/` 中的历史文件。默认多点导航最大前向指令 0.5 m/s，覆盖跟踪速度 0.1 m/s；已经保存的 Web 任务仍使用各自参数。

底盘、MGX23、手柄、雷达采集、相机、视频服务和覆盖规划模块一并启动，初始工作模式为基础待命。车辆默认急停，不自动开始任务。雷达障碍停车默认关闭，由 Web 复选框启用；雷达采集仍运行。服务就绪只代表核心桥接和网页可访问，硬件及定位有效性以页面实际状态为准。

## 查看状态与停止

```bash
bash /home/jetson/agri_robot/scripts/project.bash status
bash /home/jetson/agri_robot/scripts/project.bash stop
```

`status` 显示托管进程、接口就绪情况、急停、控制权和雷达保护状态。`stop` 先尝试请求软件急停，再停止本脚本启动的核心、后端及网页，不解除急停、不恢复任务。若后端无法确认急停，会明确输出提示并清理所属服务。

已经由本脚本正常启动时，再次执行 `start` 不重复启动，也不改变现有控制权或急停。某项服务退出时，先查看状态与日志，再 `stop`、`start`；脚本不自动重启控制任务。

原来三个终端或其他工具启动的服务不会被强行接管或终止。若已有整套服务正常运行，`start` 会报告“已由现有进程运行”并返回；若只是部分服务或端口被占用，则停止本次启动，提示先在原终端正常退出。下次 Jetson 重启后直接用新入口即可，避免与旧命令重复运行。`stop` 只管理本脚本创建的进程。

## 配置和数据

2026-11-04 起，更新后的后端与 MGX23 驱动会为新开始的 Web 任务自动保存原始设备字节、速度指令和底盘反馈，并在结束后生成轨迹、速度、横向误差和航向误差四图。数据在该次 `data/experiments/<运行ID>/raw/`、`telemetry/`、`analysis/`，部署更新、目录和统计口径见 [任务数据采集与指标分析](任务数据采集与指标分析.md)。既有驱动连续原始日志仍保留在下表位置；首次使用新功能需先构建更新过的 MGX23 驱动并在停车状态重启核心、后端。

需要使用另一份项目配置时：

```bash
bash /home/jetson/agri_robot/scripts/project.bash start \
  --config /home/jetson/agri_robot/config/jetson_system.yaml
```

修改物理参数、原点或速度配置后，应核对实际使用的 YAML，停车后停止并重新启动。默认硬件开关和启动参数保存在 `scripts/project.py` 的 `commands()` 中。

| 路径 | 内容 |
| --- | --- |
| `.runtime/project/state.json` | 本轮配置、日志目录、进程启动身份及所属标识 |
| `.runtime/project/runs/<时间_进程号>/core.log` | 核心和硬件节点标准输出 |
| 同目录 `backend.log`、`frontend.log`、`ros/` | 后端、网页及 ROS 日志 |
| `.runtime/mgx23_raw/` | 新采集的 MGX23 原始数据，每次新建带时间戳文件 |
| `.runtime/safety/` | 安全事件记录 |
| `data/web/missions/`、`data/experiments/` | 原有 Web 任务和各轮执行数据，继续按原功能保存 |

进程管理使用互斥锁、启动身份和本次启动标识，防止重复启动及重启后 PID 复用导致误停其他进程；失败时清理本次创建的进程并保留日志。不在运行中执行系统升级、依赖安装、全局配置修改或开机自启注册。
