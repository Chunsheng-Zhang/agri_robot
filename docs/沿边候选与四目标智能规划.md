## 1. 当前算法

1. 按车长、车宽、旋转中心及安全余量计算完整旋转圆包络，保持原有保守mitre内缩。固定原点和原始边界不变。
2. 遍历外环和孔洞的有效边。一条边绑定平行作业方向，以及向可作业侧半幅宽的起排位置；半幅宽小于安全净空时按安全距离放置。孔洞环与外环的可作业侧相反，并兼容输入环的正反点序。
3. 只有方向和幅宽周期内的排线位置都等价时才合并候选。两条平行边产生不同排线时保留比较。此处位置由基准边确定，没有新增独立偏移搜索或Web输入。
4. 保留PCA/垂直方向、0–165°每15°粗搜，再围绕本轮较优方向比较±5°、±2°、±0.5°。补充方向采用确定的原边界半幅宽起排规则。所有角度相对map东向、逆时针为正，按180°周期处理。
5. 同方向复用Fields2Cover原生BCD分解；仍检查扫描单调、分区并集及孔洞完整性，必要时尝试原生梯形分解。以幅宽为固定间距，将沿边扫描线向两侧延伸，覆盖所有安全分区；基准边为凹边时也不能省略另一侧支臂。
6. 原布局之外，收集横向首末侧及当前方向平行边附近的补边扫描线。仅保留相对已有作业行足迹存在正面积增益的线，比较原布局和补边集合布局。每个分区通过原生`Swaths.append`裁剪；无扫描线击中的窄分区仍保留中线，不直接删除。
7. 两套布局分别调用原生TSP，消费完整Route作业行与连接，检查所有作业行恰好访问一次、连接连续及完整车体净空。完全相同的行几何不重复求解。
8. 设置人工入口时，继续比较原生自由开放路线两个起端，以及入口引导闭环去除入口接近/返程后的两个起端；不改变人工入口与执行接近解耦的约定。
9. 按下述四目标评价完整路线，只保留最佳完整几何，同时保留全部候选的指标、评分及拒绝原因。失败或取消不发布部分最优路径。

“正面积增益”只用于构造补边候选，不代表一定采纳补行。生成阶段使用行足迹矢量近似，最终择优仍使用统一网格下完整路线的覆盖与重复率。当前比较原布局和补边集合，没有穷举所有补边子集，也不声称全局最优。

## 2. 文献依据与权重解释

采用同行评审论文作为目标选择和方法依据：

- Höffmann、Patel、Büskens，2024，*Journal of Field Robotics*，41(3):823–844，[Optimal guidance track generation for precision agriculture: A review of coverage path planning techniques](https://onlinelibrary.wiley.com/doi/full/10.1002/rob.22286)，DOI 10.1002/rob.22286。综述分别讨论转弯数、路径长度和重叠等代价，说明转弯会带来减速及额外时间/能源负担，并讨论沿边方向与复杂地块分解。支持将转弯单独评价；其以行数估计换行次数的简化不能直接当成本项目完整路线的停车转向数。
- Höffmann等，2023，*Agriculture*，13(11):2112，[Optimal Coverage Path Planning for Agricultural Vehicles with Curvature Constraints](https://www.mdpi.com/2077-0472/13/11/2112)，DOI 10.3390/agriculture13112112。支持复杂地块分解、实际连接参与路由及同时关注转弯与长度。该文车辆曲率约束与本项目履带原地转向模型不同，本项目继续用自身完整旋转包络和停车标记。
- Yang等，2025，*Agriculture*，15(14):1479，[Coverage Path Planning Based on Region Segmentation and Path Orientation Optimization](https://www.mdpi.com/2077-0472/15/14/1479)，DOI 10.3390/agriculture15141479。其四项评价是转弯、长度、冗余和规划时间，分别取0.40/0.40/0.10/0.10，并说明权重需结合车辆及任务选择。该组目标与本项目不同，不能直接照搬数值。

**文献没有给出适用于所有车辆及作业的统一四权重。** 本项目保留作业质量优先，在原三目标基础上为真实停车转向增加独立成本，采用以下初始工程偏好，未经实车经济成本标定，不表述为“期刊推荐标准权重”：

| 目标 | 方向 | 权重 |
| --- | --- | ---: |
| 整田覆盖率 | 最大化 | 0.40 |
| 整田重复覆盖率 | 最小化 | 0.25 |
| 完整路径总长度 | 最小化 | 0.20 |
| 完整执行路径停车转向次数 | 最小化 | 0.15 |

覆盖和重复合计0.65，维持当前对漏作业、重复作业的优先关注；长度保留0.20；转弯以0.15形成独立但适度的惩罚。权重是对归一化成本的偏好，不是“允许漏覆盖40%”，也不保证任意方案都达到某个覆盖门槛。代码集中在`planning_options.WEIGHTS`，不新增页面权重输入。

## 3. 可复现评分

令A为整田可评价面积（扣孔洞，含地头），W为有效作业幅宽，C/O为覆盖/重复面积占整田的百分数，L为完整平移路径长度（设置入口时含现有入口参考连接），N为执行停车转向标记数量：

```text
L0 = A / W
N0 = max(1, 2 × sqrt(A) / W)
J = 0.40 × (1 − C/100)
  + 0.25 × O/100
  + 0.20 × L/(L+L0)
  + 0.15 × N/(N+N0)
```

同一地块、幅宽的所有候选共用L0/N0，不按候选最大最小值重新缩放，避免新增候选时改变已有方案的相对量尺。N0取等面积正方形的双直角换行数量级，仅为固定无量纲参考，不是文献通用公式、实际行数、时间或能耗估计；狭长地块等场景应单独做权重/归一化敏感性分析。

N由最终采样路径的`point_turn_indices`统计，与跟踪器使用的标记一致。包含作业行之间、跨分区及绕障连接上的停车拐角；不计入口参考连接、执行接近或首次对齐；暂停后重复对齐也不增加规划N。同XY不同航向为停车转向，角差阈值沿用1e-3 rad；一次180°转向记一次，两次90°记两次，不按角度或能源加权。直线采样加密不会增加次数。

按J最小选择，同分优先覆盖率高、再优先长度短。依然没有最低覆盖率硬约束。原生TSP内部仍按库的距离代价作启发式排序，四目标在外层选择完整方案，不是对所有访问顺序的精确四目标联合最优。
