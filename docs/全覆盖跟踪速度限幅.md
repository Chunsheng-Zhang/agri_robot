# 全覆盖跟踪速度限幅

2026-11-04。按用户要求，覆盖跟踪的速度指令允许边界统一为：

- 线速度：`[-1, 1] m/s`。
- 角速度：`[-1, 1] rad/s`（用户随后将覆盖最大角速度由 5 调整为 1）。

当前底盘安全总限幅仍为线速度 ±1 m/s、角速度 ±5 rad/s，供手柄等模式使用。覆盖控制器、ROS 参数校验、后端任务模型、网页参数范围及两份启动 YAML 采用更严格的覆盖角速度 ±1 rad/s。

## 目标速度和限幅的区别

`speed` 是目标前进速度，允许 `0 < speed ≤ 1 m/s`。Jetson profile 的目标速度继续为 0.1 m/s，普通默认配置继续为 0.2 m/s；提高允许边界不会直接改为 1 m/s。

`max_angular` 是角速度指令绝对值上限，允许 `0 < max_angular ≤ 1 rad/s`，覆盖缺省值和两份 YAML 均为 1。角速度正负由跟踪误差/曲率决定，设置 1 不等于每次都以 1 rad/s 转弯。急弯时控制器仍可降低线速度以维持曲率，接近终点仍减速。

当前仍是前进式 Pure Pursuit，路径接口仍拒绝倒车段。虽然总线速度允许边界包括负值，当前跟踪算法正常只输出 `0…speed`；本次没有加入倒车跟踪，也不能给 speed 填负值来实现倒车。自动接近起点使用同一任务 speed/max_angular 上限。

任务开始前仍核对安全节点的实时限幅；若实际启动使用另一个更低的安全 profile，不能靠提高 Web 任务参数绕过安全限制。这里约束的是输出指令，不保证实际测量速度绝不超调。

## 旧任务与部署

已保存任务、历史实验和归档配置快照不修改。旧任务如果保存了 max_angular=0.5，仍可使用 ±0.5 rad/s；旧任务若保存了 5，将被新上限校验拒绝，需在网页编辑该任务的“最大角速度”为不超过 1，保存并重新规划后再明确开始。目标速度按实际需要单独设置，最大 1 m/s。

修改代码或启动 YAML 后，需要构建 `agri_path_tracking`、`agri_bringup`，并在停车、控制权释放和任务结束后重启相应核心及后端。运行中不热改限幅、不自动恢复任务；多点导航和 Web 手动控制的参数范围不随本次覆盖限幅调整。

## 代码位置

- `agri_robot_ws/src/agri_path_tracking/agri_path_tracking/controller.py`：最大允许目标速度/角速度校验，Pure Pursuit 输出计算。
- 同目录 `node.py`：启动参数校验、空闲时 ROS 参数更新校验；运行、暂停或申请控制权期间继续禁止修改参数。
- `config/jetson_system.yaml`、`agri_robot_ws/src/agri_bringup/config/system.yaml`：path_tracker 段。
- `agri_backend/missions.py`：CoverageParameters 校验。
- `agri_web/src/components/tasks/taskParameters.ts`：覆盖任务编辑范围及提示。
- `agri_robot_ws/src/agri_safety/agri_safety/gate.py`：最终速度指令限幅。
