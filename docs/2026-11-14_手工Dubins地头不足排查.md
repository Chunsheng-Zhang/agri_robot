## 原因

作业行由OpenNav/Fields2Cover产生，人工入口适配器比较四种原生起步排列，并用用户选择的同一种曲线连接作业行。四个`variant`表示起始行序和起始行驶方向组合，不是四种曲率算法，也不是四次尝试不同转弯半径。

本例相邻条带间距0.8 m，最小转弯半径1 m。相邻反向作业行不能靠直径2 m的简单半圆直接接上，原生Dubins生成外扩绕转；1 m地头无法容纳这些连接。本次逐一复现，与归档错误吻合：

| 起步方式 | 中心线净空区域外累计长度 m |
| --- | ---: |
| 0 | 75.816731 |
| 1 | 75.817954 |
| 2 | 75.967639 |
| 3 | 75.968697 |

`outside_length`是整条路径中落在`field.buffer(-robot_width/2)`外的累计长度，包含真实越界和缺少车体净空的部分；不是机器人定位偏差，也不是某个点离地块75 m。`outside_bounds`是这些路径部分在统一map坐标系下的包围盒，负坐标本身正常。

只有整条路径通过校验才发布，失败后无可执行新路径。此例拒绝有实际几何依据，不应删除或放宽检查。

这只能说明3 m在该地块、该组参数下是一个已验证可行值，没有证明它是最小或最优地头。

Dubins CC在地头1/2/2.5 m同样失败，3 m通过。Reeds–Shepp和HC即使明确允许倒车，1 m地头也都失败；不能承诺仅更换曲率或勾选倒车便可解决。本例勾选倒车但保留Dubins不会使前进专用Dubins输出倒车段。

手工3 m地头虽然通过净空，但没有独立补作业地头路径；按任务0.8 m有效幅宽、0.05 m评价网格计算，整田预测覆盖率约54.98%，不宜据此视为满意的完整覆盖方案。

另外以相同地块、幅宽、车体长宽及余量，运行当前源码的“一键优化规划”：固定原地转向、自动安全地头约0.296321 m，完整路径通过检查，整田预测覆盖97.8138%、重复覆盖0.7127%，正式路径235.7080 m，入口参考距离0.8114 m，38个停车转向点。不是实车结果，也不是全局最优证明。

若采用停车原地转向，使用“一键优化规划”；若明确要求连续曲线，手工流程需为所选曲线提供足够转弯空间，再单独核对整田覆盖质量。修改手工参数后按既有流程保存任务并重新生成。人工入口仍仅影响起步选择，执行仍直接单点接近覆盖首点。
