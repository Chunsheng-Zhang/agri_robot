# 位置/航向噪声与执行器响应

2026-11-25新增共用扰动模块`disturbances.py`。位置和航向噪声只加入控制器观测，执行器响应位于控制器输出与车辆模型之间；参考路径与模型真值不加噪声。实车代码、驱动、系统环境与运行服务不修改。

## 统一配置

平面入口`run.bash`与Gazebo入口`gazebo/run.bash`均读取`tracking_simulation/config.yaml`。下面是2026-11-25验证使用的扰动工况；2026-11-26提交时保留用户已将这四项设为0的配置，未重新启用：

```yaml
simulation:
  position_noise: 0.03
  heading_noise_deg: 0.5
  actuator_linear_tau: 0.15
  actuator_angular_tau: 0.15
```

修改现有`simulation`中的这些项即可，不必替换其他参数。每项设为0可独立关闭；将四项全部设为0可用于无附加扰动对照。旧YAML缺少两项时间常数时，缺省为0，不强制改写旧配置。随机种子仍由`seed`控制，反馈周期仍由`feedback_period`控制。

验证用的位置标准差0.03 m参考[所给论文表7](https://dergipark.org.tr/en/download/article-file/5922230#page=13)的RTK白噪声工况。航向0.5°是本项目的工程测试值。论文中的0.15 s是电液转向一阶响应时间常数；我们将0.15 s用于机器人线/角速度的附加响应测试，不能称为论文同款执行器或本车实测参数。本次没有增加累积漂移、多路径跳变或速度测量噪声。

## 数学模型与时序

每次定位采样时生成：

\[
x_o=x+\epsilon_x,\quad y_o=y+\epsilon_y,\quad
\psi_o=\operatorname{wrap}(\psi+\epsilon_\psi)
\]

其中x/y噪声相互独立、零均值、标准差均为`position_noise`，航向标准差在度与弧度间正确转换。标准差不是绝对误差上限；3 cm每轴标准差也不是3 cm平面误差上限。两帧之间保持上次观测，不在每个控制周期重新生成噪声；四种控制器使用相同配置和种子。

附加执行器模型：

\[
\tau_v\dot v_a+v_a=v_c,\qquad
\tau_\omega\dot\omega_a+\omega_a=\omega_c
\]

恒定输入区间采用精确指数更新：`u_new = u_old + (u_target-u_old)*(1-exp(-dt/tau))`。新指令先结算到发出时刻，再成为后续区间的目标，不提前作用到过去。时间常数为0的通道直接传递；这是一阶响应滞后，不是固定等待时间。

- 平面模型：车辆由`v_a/ω_a`驱动，开启响应时采用不超过5 ms的中点子步积分；关闭响应时保持原恒定速度精确积分。这里的模型实际速度等于执行器输出，两条曲线可以重合。
- Gazebo：控制器约20 Hz生成请求，按物理真值反馈时刻约100 Hz更新附加响应，再将输出发布到`/tracking_sim/cmd_vel`。ODE与原有轮端力矩/加速度/接触继续独立计算实际运动。因此请求、一阶输出、实际速度可能三者不同。附加响应未标定，不把Gazebo已有物理响应重复解释成同一时间常数。
- Gazebo的定位纯延迟`physics.feedback_delay`独立保留，位置/航向/速度同采样、同延迟交付；它不等于执行器时间常数。

普通到达和任务时限结束后，零目标也经过一阶响应，记录至少1秒且不少于5倍最大时间常数的制动过程；BRAKING不混入TRACKING误差。暂停（平面工具）、定位超时、异常和取消使用直接清零输入/清除响应状态的路径，不让残余目标恢复。Gazebo输入立即归零不代表真实物理车体瞬时静止，实际制动仍由物理模型决定。

## 数据和图

每个控制器的`tracking.csv`新增：

| 字段 | 含义 |
| --- | --- |
| `v_command_m_s / w_command_rad_s` | 控制请求，任务结束时为零请求 |
| `v_actuator_m_s / w_actuator_rad_s` | 附加一阶响应输出 |
| `v_actual_body_m_s / w_actual_rad_s` | 模型实际速度；Gazebo中来源独立于指令 |

原有位置/航向真值、带噪观测、反馈采样时刻和跟踪误差继续保留。`metrics.json`保存两类航向误差及附加执行器输出相对请求的统计；参数快照与源码指纹包含扰动模块。

各算法结果目录新增`actuator_response.png`：上下两图分别是线速度、角速度，每图三条曲线显示请求/响应输出/模型实际速度。四合一图同时显示真值与带噪观测的横向/航向误差。Gazebo每个算法的上级目录另有`actuator.csv`，记录约100 Hz实际下发的请求/响应输出、物理速度及故障清零标记，包含制动尾段；`ground_truth.csv`仍独立保存物理真值。
